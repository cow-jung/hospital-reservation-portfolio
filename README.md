# 📌 프로젝트 소개

병원 예약 시스템은 Flask를 기반으로 제작한 병원 예약 웹사이트입니다.

사용자는 병원 정보를 확인하고 회원가입, 로그인, 진료 예약, 게시판, 공지사항 등의 기능을 이용할 수 있으며,
관리자는 병원 홈페이지를 관리할 수 있습니다.

> 본 프로젝트는 HTML, CSS, JavaScript, Flask를 활용한 웹 프로젝트입니다.

---

# ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 🏠 메인 페이지 | 병원 소개 및 주요 메뉴 제공 |
| 👤 로그인 / 회원가입 | 회원 인증 화면 |
| 🏥 병원 소개 | 병원 정보 및 운영시간 안내 |
| 🩺 진료과 안내 | 진료과 정보 제공 |
| 📅 예약하기 | 진료 예약 화면 |
| 📝 게시판 | 게시글 조회 및 작성 |
| 📢 공지사항 | 병원 공지 확인 |
| 👤 마이페이지 | 회원 정보 및 예약 확인 |
| ⚙️ 관리자 페이지 | 관리자 기능 화면 |

# 🚀 실행 방법

```bash
# 저장소 복제
git clone <저장소 주소>

# 프로젝트 폴더 이동
cd hospital-reservation-web

# Flask 설치
pip install flask

# 프로그램 실행
python app.py
```

브라우저에서 아래 주소로 접속합니다.

```text
http://127.0.0.1:5000
```
